# Распознавание коротких гитарных фраз

**Статус:** русская страница кейса опубликована локально как `guitar.html`. Это офлайн-пилот на пяти собственных записях с ручной MIDI-разметкой; готовая модель Basic Pitch не переобучалась.

**Главный вопрос:** можно ли настройкой декодирования уменьшить число лишних нот и какой ценой для полноты распознавания?

**Метод:** 24 набора параметров, три записи для подбора и две заранее отложенные для проверки. Основной показатель — F1 при совпадении высоты и начала ноты в пределах 50 мс; окончание ноты в него не входит.

**Результат:** выбран вариант onset 0,6 / frame 0,5 / Melodia off. Средний F1 на двух отложенных фразах изменился с 0,843 до 0,849. Пентатоника улучшилась, Tamacun ухудшилась. На риффе F1 вырос с 0,730 до 0,887 за счёт сокращения лишних событий. Небольшую среднюю прибавку на тесте не подавать как доказательство общего улучшения модели.

**Иллюстрации:** F1 по каждой фразе, точность–полнота для 24 настроек, сравнение MIDI с ручной разметкой, отдельная диагностика риффа и одна CQT для исходного звука. Английские оригиналы лежат в `assets/guitar/en/`, русские версии — в `assets/guitar/ru/`.
