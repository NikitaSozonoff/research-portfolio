# Портфолио исследовательских проектов

Главная страница — `index.html`. Готовые русскоязычные кейсы: `guitar.html`, `paleontology.html` и `neurophysiology.html`. Страницы открываются локально без сборки и сервера.

## Где что лежит

- `assets/site.css` — общие стили.
- `assets/guitar/ru/` — пять графиков с русскими подписями в SVG; PNG-копии нужны для быстрой проверки и возможного использования вне сайта.
- `assets/guitar/en/` — сохранённые оригиналы с английскими подписями для будущей английской версии.
- `assets/paleontology/` — фотография образца и графики морфометрического анализа.
- `assets/neurophysiology/ru/` — русскоязычная сводная визуализация нейрофизиологического пилота.
- `assets/neurophysiology/en/` — исходные англоязычные рисунки итогового отчёта.
- `scripts/make_neuro_figure_ru.ps1` — воспроизводимое построение русской тепловой карты из итоговой таблицы.
- `scripts/make_guitar_figures_ru.py` — воспроизводимое создание русских SVG из исходных английских графиков без изменения данных и геометрии.
- `content/` — рабочие сведения о трёх проектах.
- `incoming/` — локальные материалы для отбора, не публикуются автоматически.

Для пересборки русских графиков укажите расположение исследовательского репозитория:

```powershell
python scripts/make_guitar_figures_ru.py --project-root "..\github-ready\acoustic-guitar-transcription-evaluation"
```

Скрипту достаточно стандартной библиотеки Python. Английские графики в исходном репозитории остаются нетронутыми. Русские SVG содержат редактируемые подписи; если понадобится полностью векторный экспорт с буквами в кривых, его можно будет заново получить при восстановлении научного Python-окружения.

## Редакторские границы

Гитарный кейс описывает пять записей одного исполнителя и две отложенные тестовые фразы; он не доказывает общего улучшения модели. Палеонтологический вывод — совместный результат публикаций, а не следствие одной кластеризации. Нейрофизиологический проект — описательный технический пилот на одном участнике, без утверждения о клиническом эффекте.
